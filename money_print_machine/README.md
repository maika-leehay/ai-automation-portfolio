# 💰 Money Print Machine (MPV2 Next-Gen)

An autonomous multi-engine AI revenue stack powered by **Google Gemini 3.6 Flash**, **Edge-TTS Neural Voiceover**, and **Kinetic Video Subtitles**.

---

## ⚡ Key Modules

1. **🎬 Autonomous YouTube Shorts & TikTok Machine (`modules/shorts_generator.py`)**:
   - Generates high-hook viral scripts across trending niches (Wealth, Stoicism, AI Tools, Dark Psychology).
   - Generates natural neural voiceover using Edge-TTS with word-level timestamps.
   - Sourced vertical 9:16 background b-roll visuals.
   - Overlays **MrBeast / Hormozi kinetic word-by-word highlighted animated captions**.
   - Exports social-ready vertical `.mp4` video.

2. **🐦 Viral Twitter / X Growth Engine (`modules/twitter_monetizer.py`)**:
   - Generates 5-part high-retention viral threads with strong hooks and calls to action.

3. **💰 Affiliate Marketing Automator (`modules/affiliate_automator.py`)**:
   - Converts any product or SaaS link into high-converting social posts and email campaigns with your affiliate tags.

4. **🏢 High-Ticket B2B Client Acquisition (`modules/lead_outreach.py`)**:
   - Drafts hyper-personalized value-first cold email proposals for local businesses and agencies.

5. **📱 Mobile Telegram Remote Control (`telegram_bot.py`)**:
   - Control the machine directly from your phone! Send `/short`, `/thread`, or `/pitch` to `@MekaouiBot` to generate content on-demand.

---

## 🚀 Quickstart

1. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run Interactive Command Center**:
   ```bash
   python main.py
   ```

3. **Run Telegram Mobile Controller**:
   ```bash
   python telegram_bot.py
   ```
